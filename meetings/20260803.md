## 3. Definitions of Terms

| Term | Definition |
|------|------------|
| Weights matrix $W$ (or $G$) | The network, written as a table: row $i$, column $j$ holds $w_{ij}$, how much household $i$ weighs household $j$'s belief. Row-normalized so each row sums to 1; $w_{ii}=0$. |
| $M_i^*$ | Household $i$'s equilibrium belief about the neighborhood, on the $[-1,+1]$ margin scale — the network analogue of the single shared $m^*$ in my existing model. |
| $\gamma$ (endogenous effect) | The strength of the social pull: how much a household's belief responds to $(WM^*)_i$, its own friends' average belief. Plays the role $\beta J$ played in the group-average model. |
| Contextual effect ($\delta$) | How much a household's belief responds to its friends' *characteristics* (e.g. their distance to school), as opposed to friends' beliefs. |
| Contraction mapping | The condition guaranteeing the belief-updating map has exactly one fixed point regardless of starting guess — Banach's theorem, distinct from mere *existence* of a fixed point (Brouwer's theorem). |
| $\lvert\gamma\rvert<1$ | The sufficient contraction bound used throughout Section 7: below it, the rational-expectations equilibrium is provably unique. |
| NFXP (nested fixed-point) estimation | A maximum-likelihood estimator that re-solves the entire network equilibrium inside every likelihood evaluation, rather than approximating it. Slower but exact; the estimation method used throughout. |
| Group vs. network structure | Group: every member responds equally to the whole group's average (a network where every tie has equal weight — a special case). Network: each member responds only to its own, generally distinct, set of ties. |
| Complete vs. incomplete information | Complete: an agent observes others' actual choices. Incomplete: an agent only forms a belief (a rational expectation) about others' choices, without observing them directly. My model and Lee's are both incomplete-information. |

## 4. My Own Thoughts

### On discussion item 1 (network-generation priority)

- **Current thought:** Experiment 3's result — that a misspecified network is worse than no
  network model at all — is, to me, an argument for prioritizing the network-generation question
  (survey name generator vs. GPS co-movement) over the `72_I_595` digest (the newtown supermarket research), since without a credible
  network the whole Lee-et-al. apparatus cannot honestly be applied to real PUDO data.
- **Reasoning:** The result is not a general methodological point I am asserting from the
  literature; it is something I generated myself, on my own toy PUDO network, this week — true
  network $\hat\gamma = 0.772$ against a true $0.60$, versus a wrong-network $\hat\gamma = 1.115$
  with the contextual distance effect sign-flipped ($0.283 \to -0.271$).
- **Alternatives I considered:** Digesting `72_I_595` first, since it was already queued and is
  Sensei's own paper. I am not confident this is the wrong call, which is why it is listed as
  Discussion Item 1 rather than decided unilaterally here.
